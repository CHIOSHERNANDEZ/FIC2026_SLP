# FIC 2026 | Festival Internacional de Cortometrajes

React + TypeScript + Vite web application for the **V Festival del Tecnológico de Monterrey - Campus San Luis Potosí** (5 al 7 de noviembre de 2026).

## Features

- **Interactive Program Schedule**: Filter and view activities for Thursday 5, Friday 6, and Saturday 7 with highlighted sessions.
- **International Guests & Partners Showcase**: Profiles for featured directors and critics alongside festival allies.
- **Logistics & Transportation**: Fleet technical sheets and daily official itineraries.
- **Local Benefits & San Luis Potosí Cultural Experiences**: Curated benefits and city cultural events.
- **Registration Integration**: Direct link to the official Microsoft Forms registration portal.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS with custom festival theme tokens
- **Typography**: Cormorant Garamond & Inter
